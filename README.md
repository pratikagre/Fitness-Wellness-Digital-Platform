# Xanso — Premium Digital Fitness & Wellness Platform

> **"Better Every Day."**  
> Fitness, movement and wellness designed around your lifestyle. Live classes, personal guidance and wellness programs — all in one place.

Xanso is an end-to-end modern digital wellness platform connecting individual practitioners, certified wellness coaches, and corporate organizations through interactive live classes, 1:1 tailored programs, on-demand masterclasses, and corporate wellness solutions.

---

## 🌟 Key Product Features & Capabilities

### 1. Interactive Homepage & Navigation
- **Header & Navigation**: Home, Programs, Personal Training, Corporate Wellness, Trainers, Live Classes, On-Demand, Pricing, Success Stories, Blog, About, and Contact.
- **Hero Section**: Exact brand copy, real-time live class ticker, certified trainer trust badges, and interactive live studio preview card.
- **Why Xanso (8 Pillars)**: Live Expert-Led Classes, Personalised Programs, Certified Trainers, Flexible Timings, Progress Tracking, On-Demand Content, Corporate Wellness, and Community & Accountability.

### 2. Interactive Wellness Goal Selector
- **Dynamic Program Matching**: Instant filters across:
  - *Get Fit*
  - *Reduce Stress*
  - *Manage Weight*
  - *Build Strength*
  - *Improve Flexibility*
  - *Improve Sleep*
  - *Overall Wellness*
- Instant program cards with level, duration, coach, price, and full syllabus access.

### 3. Choose Your Journey (Three Pillars)
- **GROUP**: Live instructor-led classes with peer energy and 24/7 library access.
- **1:1**: High-touch personalized coach assignment, weekly reviews, and direct WhatsApp / app chat.
- **CORPORATE**: Scalable wellness programs for startups, SMEs, and global enterprises.

### 4. Free 8-Question Clinical Wellness Assessment
- Multi-step guided evaluation assessing physical baseline, daily time availability, movement style preferences, consistency hurdles, and sensitivities (lower back, PCOS, joint sensitivities).
- Algorithmic recommendation engine generating:
  - Dominant wellness goal
  - Recommended journey (GROUP, 1:1, or CORPORATE)
  - Matched certified master trainer
  - Daily habit tip
  - 8-Week progression roadmap
  - Confetti celebration and instant "Start My Journey" pass activation.

### 5. Simulated Live Interactive Studio
- Realistic WebRTC studio simulation:
  - HD live stream view with trainer guidance
  - Real-time active calorie burn counter and simulated heart rate telemetry (bpm)
  - Live participant counter (300+ active members)
  - Interactive community chat feed with instant emoji reactions (🔥, ❤️, 🧘, 👏)
  - Real-time form cue overlays from the coach
  - Camera & microphone controls (privacy-first toggle).

### 6. Certified Master Trainers Directory
- Verified coach profiles featuring qualifications (E-RYT 500, CSCS, BPT Physiotherapy, MBSR, FRC), years of experience, languages, client reviews, and interactive 1:1 session slot booking.

### 7. On-Demand Content Library & HD Video Player
- Filterable catalog by category (*Yoga, Fitness, Meditation, Mobility, Relaxation*) and difficulty (*Beginner, Intermediate, Advanced*).
- Built-in video player modal with scrubbing timeline, duration, calorie estimates, and instructional notes.

### 8. Corporate Wellness & Interactive Team Estimator
- Tailored tracks for Tech Startups, SMEs, Large Enterprises, and Educational Institutions.
- Interactive workforce slider (10 to 500+ employees) with real-time package customization.
- Direct corporate proposal demo request flow.

### 9. Member Dashboard & Progress Streaks
- **Overview**: Upcoming classes, today's workout task, and quick room join.
- **My Schedule**: Day-by-day weekly movement roadmap and progress percentage.
- **Streaks & Badges**: 7-Day Streak, 14-Day Streak, 30-Day Champion, 50 Sessions, and 100 Sessions milestone achievements.
- **1:1 Trainer Hub**: Direct message simulator with assigned trainer and call scheduling.
- **Subscription & Invoices**: Current active tier, renewal dates, and downloadable tax invoice history.
- **Notifications Center**: Class start alerts and achievement unlock notifications.

### 10. Master Admin Panel
- Platform KPI metrics: Total Members (14,820), Active Subscriptions (11,430), Monthly Revenue (₹28.4L), Live Classes broadcast count.
- Member management directory with search and active plan status.
- Live class timetable scheduler.
- Corporate demo pipeline and B2B contract tracking.

### 11. Content & Success Stories
- **The Xanso Wellness Journal**: SEO-optimized evidence-based articles covering cortisol management, Yoga Nidra neuroscience, ergonomic desk syndrome, and cycle-synced PCOS training.
- **Verified Success Stories**: Authentic member transformations with verifiable before/after markers.
- **Responsible Medical & Health Disclaimer**: Clear ethical disclaimers advising physician consultation before starting new regimens.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS with custom dark luxury wellness palette (`emerald`, `teal`, `dark-obsidian`, `amber`)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti for assessment completion celebration

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```
